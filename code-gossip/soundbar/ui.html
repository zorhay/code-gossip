About Kokoro

Kokoro turns text into speech on your computer. Install downloads Python packages; the speech model downloads on first use.

What gets installed & how it works
  • Packages: Kokoro, SoundFile, PyTorch and their dependencies, plus the English spaCy language model. Allow roughly 1.5 GB for the Python environment, plus model downloads.
  • Location: an isolated Python environment at ~/.code-gossip/state/.venv. In a development install, this points into your checkout.
  • Python: requires Python 3.9–3.11. Setup looks for a compatible interpreter; if needed and uv is available, it may download a managed Python through uv.
  • Model: Kokoro-82M and voice files download from Hugging Face on first use and are cached locally (normally ~/.cache/huggingface, unless configured otherwise).
  • While running: a background process starts on first speech use, keeps the model in memory, and receives requests through a local Unix socket. It stops after 10 minutes without activity.
  • Privacy: speech synthesis runs locally once the models are downloaded. AI commentary still uses your selected AI provider to generate its text.

Audio credits

Phrase and AI commentary previews were generated with Kokoro-82M, using its preset voices. Kokoro's model weights and inference code are available under Apache License 2.0. These are our own generated recordings, not redistributed model weights.

AI commentary examples were written for an illustrated login-timeout scenario. They demonstrate the shipped styles; they are not live provider responses. Phrase previews use the exact shipped phrase text. Voice selection changes the recording you hear.

Paper and Construction use the project's bundled CC0 samples. Synthesized effects use the shipped SoX and melody definitions. Wood Thrush chooses new phrases in the browser using the local composer's musical rules and recent-note history. Each chosen phrase plays a SoX-rendered recording with the shipped envelope and reverb. System sounds use macOS alert sounds; Generals uses the shipped macOS speech generation script.

The website and installer are built from the same release source. Build metadata records the version, source hashes, and preview inputs.

# Licenses and credits

[README](../README.md) · [Architecture](../ARCHITECTURE.md)

Scripts: MIT. Bundled sampled audio: CC0. Default effects use macOS system sounds. Generals clips: generated with macOS speech.

Empires contains 52 newly generated performances of short game-associated phrases and new Code Gossip writing, using Qwen3-TTS models (Apache-2.0) and MLX-Audio (MIT). No game recordings or model weights are bundled. The [profile documentation](../code-gossip/data/sounds/empires/README.md) records phrase sources, authoring prompts, pinned model revisions, and distribution caveats.

Website phrase and commentary previews are prerecorded with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), whose model and inference code use Apache-2.0. Commentary examples are AI-written illustrations, not live provider responses.

The [interactive homepage](https://zorhay.github.io/code-gossip/) and installer share the same released UI and shipped sound settings. See [website builds and recordings](../ARCHITECTURE.md#website-builds-and-recordings) for regeneration, validation, and deployment.
